# Hotel Booking Cancellations Analysis

## 📌 Project Overview

This project analyzes hotel booking data to understand booking and cancellation patterns using Microsoft Excel.

An interactive dashboard was created to visualize hotel bookings and cancellations across different guest types, room status, hotel types, and arrival months.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Analysis
- Data Visualization

## 📊 Dashboard

The dashboard provides analysis of:

- Total Bookings
- Total Cancellations
- Bookings by Hotel Type
- Cancellations by Hotel Type
- Bookings and Cancellations by Guest Type
- Desired vs Un-Desired Room Status
- Monthly Booking and Cancellation Trends
- Arrival Date Year Filter

## 🔍 Key Analysis

The dashboard allows comparison of:

- City Hotel and Resort Hotel
- Couples, Family, and Single Guest Types
- Desired and Un-Desired Room Status
- Monthly booking and cancellation trends
- Booking patterns across different arrival years

## 🎯 Objective

The objective of this project is to analyze hotel booking data and identify patterns in bookings and cancellations through an interactive Excel dashboard.
